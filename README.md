# Nexora

Site pour apprendre Python depuis zéro, par séances courtes (5 à 10 minutes).

Publié sur GitHub Pages : https://edgarm44.github.io/Nexora/

## Développement local

    npm install
    npm run dev

## Publier

Double-cliquer sur `publier.bat` (envoie les changements sur GitHub ; la publication se fait automatiquement en 1 à 2 minutes).
